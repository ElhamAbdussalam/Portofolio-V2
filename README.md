# 🌐 Portfolio V2

The second version of my personal interactive and responsive portfolio, built using **React.js** and **Tailwind CSS**. This project is designed to showcase personal information, skills, past projects, and contact details — all in a modern design and smooth user experience.

---

## 🎯 Project Purpose

This portfolio serves as a professional representation of myself as a **Frontend Developer**, and acts as a central place to highlight:

- Personal and professional background
- Projects I’ve worked on
- Skills I’ve mastered
- Contact via form
- Clean, modern, and lightweight user experience

---

## 🔧 Tech Stack

| Technology        | Description                           |
| ----------------- | ------------------------------------- |
| **React.js**      | Component-based UI library            |
| **Tailwind CSS**  | Utility-first CSS framework           |
| **Framer Motion** | Modern animation library              |
| **EmailJS**       | Email integration for contact form    |
| **React Icons**   | Popular SVG icons for UI              |
| **Vite**          | Fast build tool (replacement for CRA) |

## 🔧 Getting Started

### 1. Clone the Repository

```
git clone https://github.com/ElhamAbdussalam/Portofolio_V2.git
cd Portofolio_V2
```

### 2. Install Dependencies

npm install

### 3. Start Development Server

npm run dev
The app will run on http://localhost:5173
